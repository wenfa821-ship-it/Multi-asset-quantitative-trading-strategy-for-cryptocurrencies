# 1.1 期权腿 · 最小结构说明书（买权利金）

**状态**：设计稿，**未接策略、未下单**。1.1 是否真的交易，仍由 `path-5` 的 IV−RV
判据（5–7 天新鲜样本、符号稳定、扣掉成本仍为正）决定；这份说明书的作用是——
等样本到齐那天，不用现场设计。

结论先写在这里：**只做币本位、近月、平值附近的单腿买入（long call 或 long put），
一次一张腿，买方最大损失就是权利金。**

---

## 1. 这份结构要解决的问题

期权腿的额度是权益的 20%，在 1.0 里**故意空置**。要把它用起来，需要的不是"看涨
就买 call"，而是两件可验证的事：

1. **入场成本可控**：买方的对手是价差。价差是多少、能不能筛掉贵的那一档，必须
   先量出来（已量，见 §2）。
2. **判据可被否证**：什么条件下买、什么时候不买，必须写成数字，而不是感觉。

### 2.3 两条已经堵死的路

* **美元结算 `BTC-USD_UM`（634 个 live）不可用**：抽 6 个到期的认购，**没有一个有
  卖价**（2 个只有一档 $5 买价，其余空簿）。

## 3. 结构定义

### 3.1 选什么

* **单腿买入**：`long call` 或 `long put`，一次一张腿。
* **只做平值附近**：`|strike/forward − 1| ≤ 2.5%`。
* **只做 25–45 天**：优先区间靠上沿（价差随到期单调收窄），但不吃 45 天以上
  的时间价值。同一时间只持一个到期。
* **标的**：BTC、ETH（SOL 见 §2.3）。

### 3.2 为什么不选其他结构（同样是结构决定，不是偏好）

| 结构 | 不选的原因 |
|---|---|
| 卖出权利金（covered / naked short） | 风险与 1.0 的"风险最小化"直接冲突；裸卖还需要保证金与强平管理 |
| 跨式 / 宽跨式（long straddle/strangle） | 方向中性、纯做多波动率，确实更贴 IV−RV 的原意，但**权利金与价差都翻倍**——在判据尚未成立前先不做，记为 1.1.1 候选 |
| 日历 / 对角价差 | 含卖方腿，同第一行 |
| 深实值 / 深虚值 | 实测价差是中位数的 2–8 倍（§2.2） |

### 3.3 方向怎么定（唯一还开放的设计选择）

买方要赚的是"已实现波动率高于隐含"（`RV > IV`），这本身**不带方向**。最小结构用
一条趋势过滤器来给方向，规则写死、不做判断：

> 日线收盘 > EMA20 → 买 call；否则买 put。（同一标的同一时刻只持一腿。）

这是**默认值，也是最弱的一环**：它把"做多波动率"变成了"做多波动率 + 一点趋势"。
1.1.1 的候选是"买平值跨式 + 用永续对冲 delta"——项目里已有永续执行路径，但需要
先证明期权本身的价差能吃得下，再谈对冲成本。

## 4. 入场闸门（全部为硬性，任一不满足即不下单）

1. **波动率判据**：`RV(30d) − IV(同到期)` 连续 ≥5 个交易日 **≥ 1.5 个百分点**。
   1.5pp 的门槛不是拍的：平值期权价格与隐含波动率近似成正比（`P ≈ 0.4·σ·√T·S`），
   所以 `ΔP/P ≈ Δσ/σ`；σ = 60% 时 1pp ≈ 1.7% 的权利金，而 §2.2 实测往返价差
   平值档约 1.5–2.2% ⇒ **成本墙 ≈ 1.2–1.3pp**，取 1.5pp 留余量。
2. **价差闸门**：该合约当下 `spread/mid ≤ 3.0%`（平值样本 p90 = 2.06%，留 50% 余量），
   且买卖两侧各 **≥ 2 档**（单边簿不可交易）。
3. **选档**：`|strike/forward − 1| ≤ 2.5%` 中**最接近 forward** 的那一档。
4. **币备足**：账户 BTC 余额 ≥ 权利金（按 ask 计）× 张数 × 1.05。
5. **额度**：单笔权利金 ≤ 权益的 **0.5%**（今天 ≈ $500，即 ATM 30d BTC 约 10–15 张）；
   期权腿未平仓权利金合计 ≤ 权益的 **2%**（第一版刻意远低于 20% 额度）；
   同标的同方向同时只 1 笔，最多同时 2 笔（BTC + ETH）。
6. **首次执行**：第一步**只买 1 张**，走通"下单 → 成交 → 记录价差/费用 → 平仓"，
   再把张数放开到第 5 条的上限。

## 5. 退出规则

| 触发 | 动作 | 理由 |
|---|---|---|
| 权利金亏损 ≥ 60% | 全平 | 有限风险不代表要扛到归零 |
| 权利金盈利 ≥ 100% | 全平 | 最小张数无法分批，先取整段 |
| 剩余到期 ≤ 7 天 | 全平（无论盈亏） | 避免被动行权：币本位到期结算会变成 **BTC/ETH 现货敞口**，即一笔计划外的裸多 |
| 价差 > 8% | 不下新单；已持仓不动 | 退出成本过高时，平仓本身也是亏损来源 |

不允许：加仓摊平、移仓到更远月、把已到期的现货结算当"长期持有"。

## 6. 落地清单（按顺序，每步都可独立回退）

1. **（等批准）** 现货换 ~$100 USDT → BTC —— 唯一剩下的前置条件。
2. 买 **1 张** ATM 30d 合约，记录：实际成交价 vs 当时 mid、实际手续费、`spread` 抽样值。
   这一步的产出是"我们的价差模型是否成立"的第一个真实数据点。
3. 把 §4 的闸门写成 `[strategies.options_premium]`（默认 `enabled = false`），
   并补测试——**先有闸门，再开门**。
4. IV−RV 判据成立后再 `enabled = true`，并按 §4.5 的张数上限运行。

  成交价必须按实际记录，不能拿模拟盘数字回测。

  已足够把它排除在 1.1 之外，直到出现反例。
