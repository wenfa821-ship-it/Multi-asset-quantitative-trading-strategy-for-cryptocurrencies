「条数够」不等于「样本够」： 同一批快照全来自一天，仍然不能用来调阈值 —— 所以这里数的是日期与不同标的。

筛选漏斗（累计）：把「不好」与「不知道」分开

「不知道」是我们的覆盖缺口，不是币的问题： 补字段每轮只覆盖 20~80 个候选，而每轮记录 300~400 个。 只有 age / turnover / liquidity 三道在做真正的质量判断。 「数不成立」= 不可能的值（例如 GT 把 sui 池子的创建时间报成 1970 → 池子「57 岁」）， 已从「不好」里单独分出，并进 data/candidates/rejections.jsonl 的判决台账。
